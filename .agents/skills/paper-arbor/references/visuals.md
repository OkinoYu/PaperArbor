# 可视化与叙事组件

图形减少读者需要补的连接，不作装饰。保留暖纸、森林绿、少量琥珀。颜色之外用文字、边框/符号区分。

| 理解障碍 | 合适的图 | 保留证据 |
| --- | --- | --- |
| 样本怎么走 | 架构原图 + 输入输出解读 | Figure / 页码 / 模块与分支 |
| 变换在哪里 | 局部前后状态 SVG | 对象/形状、真实箭头、来源与省略项 |
| 训练测试混淆 | 并列路径/阶段表 | 可训练参数、监督、测试保留组件 |
| 代际差异 | 同维度矩阵/选择器 | 保留/替换/新增/缺口 |
| 消融难理解 | 同协议表/少量条形图 | 模型、控制条件、单位、精度、负例 |

优先原始承重图。重绘是解释，不是更完整实现；无来源的维度用符号或注明未知。正文解释图的看点、机制和结论。

## 图形验收

- SVG 有 viewBox、role=img、唯一 title / aria-labelledby；箭头为真实流向，梯度/监督独立标注。
- 大图分总览与细节。手机总览宜竖向，细节允许滚动；容器有 tabindex、label、提示。图内不能截标签/箭头。
- 定量图有单位、轴、基准与精确标签。协议可比才共轴；不以缩轴/面积夸大差异。理论成本不当实测速度。
- 原图保留 panel、标注、图例，以可读为先。Caption 给版本、Figure、PDF 页、裁切/重绘、出处、看点；论文图版权与代码许可分开。

## 渐进展开

`details.qa` 放自测、可选实现细节；核心机制、结果条件和限制默认可见。`.reading-route` 提供目的明确的跳转；`.mechanism-step` 放单个运算阶段与自然段解释。

`.generation-switch` 包普通按钮 `data-panel="panel-id"` 与 `.generation-panel`。JS 才折叠未选面板，无 JS 全部保留；按钮 aria-pressed，面板标题解释差异。不能把类比当实验。

渲染器内嵌 evidence；source links 可查看同章 claim，Evidence 入口按 anchor 查询。普通 href 保留，无 JS 可查静态来源。相关阅读注明“共同来源/标签”，不自动宣称继承。
