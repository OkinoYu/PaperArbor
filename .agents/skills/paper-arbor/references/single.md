# Single / 单篇精读

读者能解释问题、画出方法路径、分开训练与推理，并定位结论证据与限制。以下是内容职责，不是固定章节模板。

1. **导读 / Overview**：身份、版本、任务与范围；概括问题、机制、最能检验它的发现。数字有来源，不逐句翻译 abstract。
2. **Motivation / Core Insight**：具体任务说明前作在哪个操作受限，交代最相关前作关系；首次术语解释，后文回到同一任务。
3. **Architecture / Method**：整体图先给路径，再按真实计算阶段展开。使用 [mechanisms.md](mechanisms.md) 拆解；核心创新详细，常规模块只讲必要背景。正文指出图中支路和变换。
4. **Training / Inference**：阶段、监督与参数更新明确，从测试样本走到输出；共享架构不等于共享配方。
5. **Experiments / Ablation**：主结果、最能检验主张的消融/诊断、负例和未控制因素；讲清“证据支持什么”，不摘排行榜。
6. **Limitations / Takeaways**：区分作者限制、编辑判断与材料缺口；保留机制与使用条件。折叠自测只挑能检验理解的问题，不凑数。

不适用的训练/消融合并为范围说明。数据论文拆构建、标注、污染；理论论文拆假设、命题、证明。解释性伪代码标明未覆盖实现细节。

先保证核心方法可恢复，再补相关工作和次要超参。读者只能说“用了 attention / RL / 蒸馏”时，回到输入、运算与监督重写。启发仅在具体有据时加入，不强制金句。
