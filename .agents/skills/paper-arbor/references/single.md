# Single / 单篇精读

以一个具体任务解释动机，交代前人缺陷和作者的入口。Overview 给身份、日期、版本和研究定位。Core Insight 用机制解释为什么可能解决问题。Architecture 给整体流图，Method 按真实算法步骤解释，不按术语词典罗列。

Training 写数据来源与处理、阶段、冻结参数、Loss、监督 token/标签、训练策略和公开超参；未知项标记。Inference 从用户输入走到输出，说明计算和部署限制；只有论文研究过时才展开 test-time scaling。Experiments 写任务、split、baseline、指标方向与关键数字；用最能检验主张的实验，而非挑最好看的分数。Ablation 说明对照控制变量、结论与不足。

结尾区分论文局限与自己的技术评估，给可带走的机制结论。必要时提供复现实验清单或短伪代码（标注解释性），不能让伪代码冒充官方代码。原图保留最能解释方法/证据的部分。章节可调整，精度和机制细节不因版式而压缩。
