01 · 导读：剪掉视觉 token 后，模型还会用剩下的吗？

视觉压缩后的错答不一定意味着证据已经消失。SCOPD 先在固定同一份稀疏视觉表示下重复生成，发现不少正确轨迹仍可恢复；再让稀疏上下文学生沿自己的前缀，向完整视觉上下文教师学习。SCOPD+ 进一步只在对少量额外视觉预算敏感的回答位置上蒸馏。它改的是语言模型利用压缩特征的能力，不是提出一个新的剪枝器。[v1 · §1、§3，pp.1–6]

三个问题要分开：诊断回答“同一稀疏表示还能生成正确推理吗”；SCOPD 回答“怎样把潜在可恢复性变成更可靠的单次生成”；SCOPD+ 回答“哪些生成位置更值得接受完整图像监督”。重复采样是研究诊断，不是部署时必须运行 Pass@64。[v1 · §3.1–3.3、Appendix A，pp.4–6、17–19]

02 · 动机证据：固定表示的 Pass@K

先看 Figure 1 左上：天气题的稀疏视觉输入只生成一次，greedy 给出错误路径，随机采样可出现另一条正确路径。左上是机制示意，不是500例数值诊断样本的实际日志。再看左下 Pass@K 曲线：模型、问题与剪枝结果都不变，只改变语言生成轨迹。右侧雷达图展示主实验的相对恢复，不能与左侧诊断队列混成同一个指标。[v1 · Figure 1、§3.1，pp.2、4]

诊断集为 500 个自由形式数值问答、493 张不同图像，来自 MMStar / CVBench / MMMU-Pro / BLINK / LogicVista / LLaVA-CoT，分别 160 / 64 / 57 / 70 / 33 / 116 题。它们预先选择为未剪枝模型能 greedy 解对的样本；选择题仅在去掉选项后仍有独立数值答案时才纳入。它不是这六个数据集的正式全量评测，也不是随机代表整个任务空间。[v1 · Appendix A，p.17]

模型固定为未适配的 Qwen2.5-VL-7B-Instruct；VisionZip 留 10% 视觉 token，诊断中为 5% dominant＋5% contextual，并固定同一剪枝表示。每题采样 64 条回答，温度 0.7、top-p 0.95、top-k 50、最多 1,024 新 token，无 repetition penalty；greedy 单独生成。语言对照删除图像和视觉占位，其余文本与采样条件相同。[v1 · Appendix A，p.17]

作者不仅匹配最终答案，还用 gpt-6-astra、reasoning effort=max 作有效性 judge：输入原图、问题、参考答案与完整回答，要求决定性观察和操作有依据；答案关键幻觉、错误运算、无依据猜测被拒绝，不确定也计失败。它可避免“数值恰好答对、却数错对象”的假恢复，但仍是自动裁判，不是人工穷尽验证。[v1 · Appendix A、Figure 5，pp.18–19]

03 · 架构：共享编码，三种视觉预算

读图路线：左侧月相题先展示“teacher 与 student 不同”不等于“加一点视觉信息就会变化”；右侧图从视觉编码器出发，完整表示给教师、预算 b 给学生、预算 b+δ 给干预学生。学生在 b 处生成回答，三个分支评分的是同一回答前缀；紫色分支只产生 JSD 敏感度，绿色 mask 决定哪些位置使用教师 KL。干预分支不再生成一条新答案。[v1 · Figure 2、Eq.1–9，pp.5–6]

视觉输入如何被压缩

输入图像先由冻结视觉编码器产生特征。默认 VisionZip 在语言模型消费这些特征之前做压缩：按视觉自注意力重要性保留 dominant tokens，其余特征按 key-feature 相似性分组，合并为少量 contextual tokens。没有 CLS 时，重要性用其他视觉 token 指向该 token 的平均 attention 估计。压缩序列再经过投影接口送入语言模型。这里既有保留也有合并，不是简单地抹掉原图九成像素。[v1 · Appendix C，pp.20–21]

b 的分母是预处理并实施视觉 token cap 后的序列长度；默认训练 cap 为 1,280。VisionZip 与问题和生成文本无关，因此一次生成内压缩视觉上下文固定。若原图达到 cap，10% 约对应 128 个视觉 token，这是说明性计数，具体舍入和 dominant/contextual 分配须实现核查。主评测图像 cap 更大，不能把所有测试样本都说成 128 个 token。[v1 · Appendix C，pp.21–22]

学生生成，教师只评分

给文本 x、完整视觉序列 Z，学生用 Zᵇ=P_b(Z) 生成回答 ŷ。每个位置的 pᵇ=pθ(·|x,Zᵇ,ŷ<t)，教师 q=pθ̄(·|x,Z,ŷ<t)；θ̄ 是学生参数的 EMA。完整视觉输入是教师特权，不需要真实答案或参考推理加入这个默认教师。三分支比较词概率，不是将完整教师的另一条推理文本当 SFT 标签。[v1 · Eq.1–4、Appendix C，pp.5、21]

一个月相样本走法：图像编码 → VisionZip压缩 → 学生用稀疏图特征写推理及答案 → 教师在这段学生前缀上、用完整特征给下一词概率 → dense SCOPD 每个回答位置接受 KL；SCOPD+ 另在稍丰富视觉特征上用同一学生评分，按敏感度挑位置。月相词条和两类分歧来自 Figure 2 的教学示意，不是完整真实 rollout 日志。[v1 · Figure 2、§3.2–3.3，pp.5–6]

04 · SCOPD：完整教师到稀疏学生的 forward KL

ℒiSCOPD=1Ti∑t=1TiDKL(qi,t∥pi,tb)

i 为样本，Tᵢ 为该生成回答的长度，t 为回答位置；q 与 pᵇ 是该位置的下一词分布。D_KL(q∥pᵇ) 表示教师到学生的 forward KL：教师认为有概率的词，如果学生给得过低，会产生监督。q 作为 EMA 目标，不通过此 loss 优化教师；学生更新的是语言模型 LoRA。原文数学目标遍历概率分布，v1 没有明确训练实现是否截断词表、蒸馏温度和有效 token mask，因此本页不借用其他蒸馏论文的 top-k 配置。[v1 · Eq.4、§4.1、Appendix C，pp.5–6、21]

SCOPD 的 on-policy 来自采样前缀：监督落在稀疏学生自己实际访问的文本状态，训练与部署使用同类压缩输入。它不自动等于 RL；默认没有正确答案奖励、value head 或 GRPO advantage，GRPO 是单独基线。教师看完整图可更有信息，但仍可能在学生错误前缀上产生不可靠目标。[v1 · §3.2、§4.1、Appendix C/E，pp.5–7、21–23]

05 · SCOPD+：用视觉预算扰动挑回答位置

预算 b+δ，不是第二条回答

SCOPD+ 默认 b=10%、δ=1 个视觉保留百分点，因此 b⁺=11%。它复用同一 encoded Z，按更大预算得到 Zᵇ⁺，然后同一当前学生在同一个 ŷ<t 上产生 pᵇ⁺。不增加一次视觉编码或新的随机 rollout，但需要一份更丰富压缩表示和额外语言模型前向。δ=1 个百分点等于当前 10% 稀疏长度约增加 10%，不是稀疏序列只增加 1%。[v1 · Eq.5–6、§4.1，p.6]

干预边界

两个预算来自同一编码特征，但 v1 没有要求 11% 的压缩 token 必须是 10% 的严格超集。VisionZip 还会合并 contextual tokens；重新压缩可能同时改变其内容或分组。所以这是预算扰动的操作性视觉响应，不是已证明只添加一条孤立证据的因果实验。[v1 · Eq.5–6、Appendix C，pp.6、21]

mi,t=12(pi,tb+pi,tb+)
Si,t=12DKL(pi,tb∥mi,t)+12DKL(pi,tb+∥mi,t)

Sᵢ,ₜ 是一个生成位置上的标量 JSD；它比较两个学生的下一词分布，教师 q 不参与这个敏感度公式。m 是两者混合。JSD 对称且有界，不预先认定更高预算的预测就是正确目标。大的 S 表示“加一点视觉预算后概率明显变化”，不是“这个 token 一定答错”或“教师–学生 KL 一定大”。[v1 · Eq.7，p.6]

按时间位置 Top-K，再平均教师 KL

𝒦i=TopK({Si,t}t=1Ti,⌈ρTi⌉)
ℒSCOPD+,i=1|𝒦i|∑t∈𝒦iDKL(qi,t∥pi,tb)

ρ 默认 10%，𝒦ᵢ 是生成时间位置集合，⌈·⌉ 向上取整。这个 Top-K 是回答位置选择，与诊断采样的 top-k=50（词表采样截断）无关，也不是选择图像 token。SCOPD+ 不用 JSD 当最终蒸馏 loss；最终目标仍是完整教师到预算 b 学生的 forward KL。它只在选中位置产生直接 KL 项，并按 |𝒦ᵢ| 平均，所以“只选一成位置”不等于 loss 强度降到一成。[v1 · Eq.8–9、Appendix A，pp.6、17]

这些位置的损失仍通过共享 LoRA 参数和其前缀依赖产生梯度；不能把“选择回答位置”说成“只有相应 token 的专属参数会更新”，也不能未经测量就推断反向计算恰好减到一成。推理时只需学生正常解码，不需要知道未来哪些生成位置敏感。[v1 · Eq.9、Appendix C/G，pp.6、21、24–25]

真实案例：大 KL 可以只是同义词

“shows / depicts” 位置的 teacher–student KL 为 0.791706 nats，但 S 只有 2.513×10⁻⁴；“road / street” 的 KL 为 0.500254 nats、S 为 9.691×10⁻⁵。图中 10% 和 11% 学生概率很接近，而教师偏好另一个近义表达。这支持用预算干预测视觉敏感度，避免将普通措辞差异全当作关键视觉监督；它仍不是所有高 KL 位置都无用的证明。[v1 · Appendix B、Figure 6，pp.19–20]

06 · 配方与推理：学习语言端，保留剪枝部署

实际测试样本走法

图像或视频＋问题 → 冻结视觉编码 → 指定预算剪枝/合并 → 合并LoRA后的学生语言模型 prefill → greedy 自回归生成推理与答案 → 提取 answer。教师和 b⁺ 干预在推理中移除；不需要多采样或额外敏感度计算。压缩减少送入语言模型的视觉序列，但先前完整视觉编码并没有因此消失。[v1 · Appendix C/G，pp.21–22、24–25]

图像评测视觉 cap 为 4,096；视频均匀采 32 帧，最多 12,288 视觉 token。所有方法用 VLMEvalKit、同一 reasoning prompt、greedy 解码，要求先输出 <think>…</think> 再输出 <answer>…</answer>。主要结果是最终答案评分：直接匹配不明确时由 Qwen3.6-27B 判断语义正确性；它只处理答案归一化/匹配，不审查推理轨迹。诊断用的 gpt-6-astra 原图推理有效性 judge 是不同环节，不要混用。[v1 · Appendix A/C，pp.17–19、22]

基准涵盖一般感知、数学与逻辑、幻觉、空间和细粒度任务；MathVerse 对应 MathVerse-VO，MME-RW 为 MME-Realworld-Lite，视频的 TempCompass 对应 MCQ。具体样本数、全部子 split、评测最大新 token 与停止设置本篇没有逐项重述，不能用诊断的 1,024 新 token 参数替代整套主实验设置。[v1 · Appendix A/C，pp.17、22]

部署含义

可以把 SCOPD+ 当作剪枝模型的后训练适配，而非一个新的推理时工具链。是否值得训练，要结合真实工作负载、视觉预算、回答长度和硬件测量；13项平均分与训练增量表不能单独回答端到端部署收益。[v1 · §4、Appendix G，pp.7–9、24–25]

分析判断

本篇最稳的结论不是“视觉证据从不丢失”，而是：在所测压缩设置里，一部分证据还在却用得不可靠；完整上下文自蒸馏可改善这一点，视觉预算响应可帮助分配监督。5% 的剩余缺口、局部负例和共享教师塌缩共同限定了可用范围。[v1 · §3–4、Appendix D/G，pp.4–9、22–25]

复述一次完整路径：冻结编码图像 → VisionZip压缩为 Zᵇ → 学生生成推理与答案 → 完整上下文 EMA 教师评分同一前缀 → dense SCOPD 平均所有位置 forward KL；SCOPD+ 额外用同一学生在 Zᵇ⁺ 上评分 → 两个学生分布的 JSD → 按回答位置选 topρ → 平均选中位置教师 KL → 更新 LM LoRA。部署合并 LoRA，仅使用原稀疏学生路径。[v1 · Eq.1–9、Appendix C，pp.5–6、20–22]

自测：为什么 Pass@64 不等于部署精度？

它在固定诊断样本上检验多次采样至少有一个validresponse，需要额外采样和判定；主部署评测是greedy单条回答，且数据范围不同。

自测：敏感度 JSD 中有没有教师？

没有。S比较同一个学生在b和b+δ视觉预算下的词分布，教师仅提供最终forward KL目标。

自测：10%视觉与10%位置是同一个对象吗？

不是。b限制视觉序列，ρ选择语言回答位置；诊断采样top-k50又是词表采样截断。它们有不同分母。

自测：为什么只选10%不能说训练算力减90%？

先要前向计算所有位置的敏感度，选定KL也仍依赖前缀和共享参数；AppendixG实测SCOPD+比dense有额外FLOPs。
