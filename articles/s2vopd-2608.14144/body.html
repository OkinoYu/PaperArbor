01 · 导读：监督来自谁看得更清楚

同一张图、同一个问题、同规模模型，为什么还能蒸馏？S²VOPD 把学生看到的图像适度退化，让教师保留原图，再沿学生自己生成的答案逐 token 校准分布。核心不是额外的正确答案，而是可恢复、仍与问题一致的视觉信息差。[v1 · §1、§3.1，pp.1–4]

论文最有力的证据链：输入不对称能产生收益；固定教师仍保留大部分收益；但裁掉问题所需证据时，更大的分布差异反而对应更差结果。这三件事共同限定了方法成立的条件。[v1 · §4.3–4.4，Figure 2、Table 4，pp.8–9]

02 · 动机：把能力优势换成输入优势

传统 OPD（on-policy distillation，在策略蒸馏）让学生先生成，强教师在学生遇到的前缀上给出下一 token 分布。OPSD（在策略自蒸馏）可取消独立强教师，但往往给教师参考答案、环境反馈或真实关注区域。S²VOPD 反转这个方向：教师不获得答案或区域，学生少看到一部分视觉信息。与图像表征的跨视图一致性学习相通，但监督对象换成了生成过程中的词概率分布。[v1 · §1–2，pp.1–3]

用一个贯穿的教学例子理解：问题是“猫前爪搭着的物体是什么颜色？”教师看清楚原图，学生看降采样图。学生若生成“搭着蓝色……”，教师仍在“搭着”这一相同前缀上，根据原图给“粉色”等 token 更合适的概率。这里没有把教师完整答案当标签；也没有在训练时告诉教师正确颜色。这个例子依据 Figure 1 的猫图解释接口，不是论文报告的定性实验或真实 rollout。[v1 · §3.1、Figure 1，pp.3–4]

分析判断

“自监督”指这个后训练目标不消费答案、奖励或区域标签。输入仍是图像–问题对，起点仍是已有 VLM；论文并未证明从未标注原始图片、随机初始化模型出发也能学出同样能力。教师看得更多也不保证每个 token 都更正确。[v1 · §3.1、§4.1，pp.3、6]

03 · 整体架构：先生成，再在同一前缀上评分

读图路线：先看上方教师的原图 x 与下方学生的增强图，再沿两条策略分支走到词分布，最后看右侧 per-token divergence。下方算子面板决定学生损失了什么信息。原图中的 “Same” 不能理解为训练后参数完全相等：架构同源，教师参数是学生参数的移动平均；两者共用的文本前缀来自学生。[v1 · §3.1、Figure 1，pp.3–4]

第一步：拆成两种视图

输入是图像 x 与问题 q。教师保留 x，学生接收 x̃=T(x)。默认只改图像，不改问题；本方法没有新增视觉编码器或问答头。沿用底座 VLM 的视觉到语言通路，贡献集中于训练数据流与目标。[v1 · §3.1–3.2、§4.1，pp.3–6]

第二步：学生决定被监督的状态

学生根据增强图和问题采样回答 y，获得一连串前缀 y<t。教师不另行采样一条答案来对齐；它接收这条学生答案的同一前缀，用原图算下一 token 概率。因此学生即使走到错误分支，监督也仍落在它实际访问的状态上。原文的 on-policy 是相对于当前退化视图学生策略；最终正常图像测试的输入分布仍有差异，不能说训练与推理所有条件完全一致。[v1 · §3.1、Eq.1，p.3]

第三步：比较词分布，更新学生

每个位置得到教师分布 Pₜ 与学生分布 Qₜ。两者限定到教师 top-k token 的共同集合并重新归一化，算 JSD，沿回答位置取平均。优化对象为学生参数 θ；教师参数 φ 由 EMA 更新，充当当前评分目标。论文没有另设答案正确性奖励、价值函数或参考策略惩罚。具体训练实现的梯度与采样处理仍需代码核查。[v1 · §3.1、Eq.1–2，pp.3–4]

04 · 目标：监督概率分布，不监督一条教师答案

ℒ(θ)=𝔼(x,q)∼𝒟𝔼y∼πθ(·|x~,q)[1|y|∑t=1|y|D(Pt∥Qt)]

这里把原文 Eq.1 的长条件分布缩记为 Pₜ=πφ(·|x,q,y<t)、Qₜ=πθ(·|x̃,q,y<t)。𝒟 是图像–问题数据集，y 是学生采样的 token 序列，|y| 是回答长度，t 是回答位置。外层期望遍历样本，内层遍历学生轨迹；先对一个回答的 token 散度取平均，再取期望。训练的可见目标是让 Qₜ 接近当前 Pₜ，不是最大化标签答案的概率。[v1 · Eq.1，p.3]

mt=αPt+(1−α)Qt
DJSα(Pt∥Qt)=αDKL(Pt∥mt)+(1−α)DKL(Qt∥mt)

mₜ 是两分布的混合，α 是混合权重；默认 α=0.5，教师与学生各占一半。每一项 KL 都是“各自分布 → 混合分布”，因此不能把默认目标简称为“学生到教师的 reverse KL”。默认 JSD 有界，分布重叠小也能保持有限值。先选教师 top-k 的 token 集合 Sₜ，再分别用各自落在 Sₜ 中的总概率归一化；选择依据来自教师，支持集合并不是两个模型各自 top-k 的并集。k 的具体取值未在 v1 给出。[v1 · §3.1、Eq.2，p.4]

说明式的边界

共同支持意味着丢弃其外的词概率；不会强制学生恢复完整词表尾部。答案前缀中已经出现的错误也不会被这一步直接重写，只会影响当前训练梯度与以后的策略。论文给出期望目标，却未写清实现是否处理采样分布的梯度、是否使用 rollout 重要性权重或 token mask；本页不把这些空缺补成 PPO/GRPO。[v1 · Eq.1–2，pp.3–4]

另一个关键边界：按印刷版 Eq.2，直接代入 α=0 或 α=1 都得到零；但 Table 6 把端点叫作 forward / reverse KL。因而默认 α=0.5 的式子可明确解释，端点实现尚不能从这条式子恢复。详见核查章。[v1 · Eq.2、Table 6，pp.4、10]

05 · 增强：信息差要大到能学，小到仍能回答

增强 T 的设计包含三个控制层：全局是否增强、各算子是否启用、启用时的强度与固定组合顺序。全局不增强时学生拿原图；增强时按算子概率独立抽样。教师始终看原图。默认配方全局概率 p=1，每个样本先降采样，再以概率 0.5 加噪声。[v1 · §3.2、Eq.3–6，pp.4–6]

T(x)=Anoise(Adown(x;s);λnoise),s∼𝒰(0.3,0.6)

s 是采样的缩放系数，A_down 将图像降采样且不放大回原尺寸，因此学生通常消费更少视觉 token；λ_noise 指噪声强度。噪声采用 DDPM 前向过程的 step 200，作者描述其近似标准差 σ≈0.11、信号衰减很小。不是每张图都加噪声，但每张图都会降采样。像素归一化域、DDPM schedule 和处理器的尺寸约束未公开，不能只靠 σ 复现像素值。[v1 · Table 1、Eq.6，pp.5–6]

06 · 训练配方与测试路径

本文做已有 Qwen3.5 的后训练，不重新训练一个独立强教师。学生 θ 是被优化的策略；教师 φ 按移动平均更新。正文未细分视觉编码器、连接层、语言模块的冻结状态，也未给出 LoRA / 全参数训练选择；因此“优化 θ”不能替代逐模块可训练配置。[v1 · §3.1、§4.1，pp.3、6]

φ←(1−η)φ+ηθ,η=0.05

η 是学生新参数混入教师的比例；默认 η=0.05 等价于教师 decay=0.95，两个命名方向相反。移动平均缓和目标变化；教师不靠正确答案单独训练。确切初始化和 EMA 更新的执行时机需配置核查。[v1 · §3.1、§4.1、Table 5，pp.3、6、10]

分析判断：可迁移的边界

教师也是底座的派生模型，可能保留系统性错误；较清楚的图像不能替代事实标签。研究主要是两种 Qwen3.5 底座和有限感知/数学基准，不能直接推广到视频、交互代理或跨架构教师。增强强度搜索没有重复运行误差或独立选择集说明，难以判断小分差是否稳健。[v1 · §3.1、§4，pp.3–10]

作者明确说明：几何变换可能改变空间问题的答案，裁切可能移除问答证据；固定教师仍有效，但增强一旦令学生样本不可回答，增大 discrepancy 没有保证。方法的实际可用条件是有足够可靠的底座视觉能力，并能构造不改题意、仍留有可答证据的退化视图。后半句是基于机制与实验作的使用条件分析，尚无逐任务的自动筛选器。[v1 · §3.2、§4.3–4.4，pp.4–5、8–9]

11 · 留下什么：监督是一种受控的信息差

可以复述的方法：图像–问题对拆成干净教师视图与退化学生视图；学生自己生成回答；教师用干净图在同一前缀上给词分布；教师 top-k 共同支持上做归一化与 JSD；学生更新后教师做 EMA。测试部署学生，训练不消费答案或区域标签。[v1 · §3.1–4.1，pp.3–6]

最值得迁移的是实验逻辑：先确认无增强是否失效，再控制增强强度和任务语义，再用固定教师判断收益是否主要依赖教师进化。本文证据指向“视图不对称比持续变强的教师更关键”，而不是“退化越重越好”。[v1 · §4.3–4.4，pp.8–10]

自测：教师为什么必须接收学生的前缀？

因为 on-policy 要在学生访问的生成状态上给监督。若教师自己采样答案再令学生照抄，就改变了监督前缀来源，不再是本文路径。

自测：给学生完全不可辨的图会更有用吗？

不保证。裁切诊断表明更大 JSD 可能伴随更差准确率；当视觉证据消失，学生只能依赖先验，无法可靠恢复每个样本的答案。

自测：蒸馏 top-k 是否就是数学推理 top-k=20？

不是同一个超参。前者限制用于计算散度的教师词支持，v1 未给出其 k；后者是数学评测时的采样设置。

自测：77.44、76.35、75.33 分别是什么？

77.44 是 FineVision-12K 训练后 Table 2 的六项感知 AVG；76.35 是 Vision-OPD-6K 下 4B 的六感知均值（Table 4）；75.33 是同数据 4B 的九项感知+数学均值（Table 3）。
